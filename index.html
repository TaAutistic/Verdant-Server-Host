Product vision

Everything in one place.

Verdant is being designed around a straightforward desktop workflow. These are development goals; individual features may not yet be implemented.

▣

Server management

Create and manage server installations, edit configuration files, and control server processes from a desktop interface.

⬡

Mod management

Plan, browse, install, and update compatible mods through supported integrations, including Modrinth and authorized CurseForge access.

↻

Automation & reliability

Reduce repetitive setup work with version checks, dependency handling, download validation, and backup workflows.
