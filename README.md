## Overview

Verdant Server Host is a Windows desktop application designed to simplify creating, hosting, configuring, and managing Minecraft servers.

The goal is to bring essential server-management tools together into one accessible interface, reducing the need for complicated manual configurations, command-line operations, and repetitive file management.

Verdant is being actively developed, with a focus on reliability, performance, and ease of use.

## Planned Features

### Server Management
- Create and manage Minecraft server installations.
- Configure server properties through a graphical interface.
- Start, stop, and restart Minecraft servers.
- Monitor server status and resource usage.
- Manage server directories, files, and configurations.

### Mod Management
- Browse Minecraft mods through supported distribution platforms.
- Integrate with Modrinth's public API.
- Integrate with CurseForge through approved API access.
- Install compatible mods automatically.
- Detect required mod dependencies.
- Check compatibility between mods, Minecraft versions, and mod loaders.
- Import existing mod files and modpacks.
- Identify available mod updates.

### Automation
- Simplified server installation and configuration.
- Automated handling of supported mod dependencies.
- File verification and download error handling.
- Server configuration backup and restoration.

## Development Status

Verdant Server Host is currently under active development.

The application is not yet considered a stable public release. Features listed in the roadmap are development targets and should not be interpreted as completed functionality.

Public downloads and detailed installation instructions will be provided when the application is ready for release.

## CurseForge & Modrinth Integration

Verdant aims to provide convenient Minecraft mod discovery, installation, and management.

Modrinth integration is planned around its documented public API.

CurseForge integration is planned around official, authorized API access, while respecting platform requirements and mod-author distribution permissions.

Automatic downloads will be provided where supported and permitted.
